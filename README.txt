나주빛달 훈련 페이스 v1.1.0

배포: ZIP을 풀면 index.html이 바로 나오는 정적 PWA입니다. 기존 원클릭 배포 앱에서 새 앱으로 최초 1회 배포하세요.
최초 배포 후 projectId, 프로젝트 이름, Production URL을 별도로 기록하고 이후 같은 프로젝트 Production에 덮어쓰기하세요. ZIP 자체는 아직 배포되지 않았으며 확정 URL은 없습니다.

업데이트: 앱 이름, manifest id/start_url/scope, Production URL을 유지하세요. 파일 수정 시 sw.js의 CACHE 버전과 화면 버전을 함께 올리세요. index.html/data.js/app.js/style.css 등 모든 변경 파일을 함께 배포하세요.
온라인에서는 네트워크 우선으로 최신 파일을 읽습니다. 앱 열기·화면 복귀·실행 중 60초마다 서비스워커 업데이트를 확인합니다. 새 서비스워커 활성화 시 화면을 다시 불러옵니다. 오프라인에서는 마지막 저장된 파일을 사용하며 즉시 업데이트할 수 없습니다.
서비스워커는 이 앱의 이전 파일 캐시만 정리하며 localStorage/IndexedDB 사용자 데이터는 삭제하지 않습니다.

표: 대화에서 정한 지도용 ±초 설정입니다. 공식 VDOT 계산이나 검증된 보편적 처방이 아닙니다. 빠른 훈련은 공식 계산기와 실제 수행 능력을 확인하세요.

상단에서 5K/10K 선택 가능. 5K는 사용자 지도용 공식 (5K×2)+90초로 10K를 추정합니다. 환산값은 실제 10K 기록과 다를 수 있습니다.

하단 한 장 이미지 만들기/이미지 공유: 현재 입력 기록의 14종 페이스를 PNG로 생성합니다. 직접 파일 공유는 지원 브라우저에서만 가능하며 미지원 시 이미지 저장 후 첨부하세요.
